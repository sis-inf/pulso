## Retrospectiva del sprint
**Lo que funcionó bien:**
- Comunicación clara entre equipos durante reuniones diarias.
- Uso efectivo de herramientas de seguimiento (Jira, GitHub).
- Integración fluida de nuevos desarrolladores.

**Áreas de mejora:**
- Algunos módulos tuvieron retrasos en la revisión de código.
- Necesitamos un proceso más estructurado para la planificación de tareas.
- Mejorar la documentación técnica para nuevos miembros del equipo.

**Acciones para la próxima iteración:**
- Establecer horarios fijos para reuniones de planificación.
- Implementar un check-list estándar para PRs.
- Aumentar el tiempo dedicado a la documentación técnica.
