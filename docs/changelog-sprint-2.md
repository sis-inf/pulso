## Retrospectiva del sprint
**Lo que funcionó bien:**
- La estructura de trabajo en equipo permitió una comunicación clara y eficiente.
- Los módulos se desarrollaron de forma modular, facilitando la integración posterior.
- El uso de herramientas de seguimiento (Jira, GitHub) mejoró la visibilidad del progreso.

**Áreas de mejora:**
- Algunos desarrolladores notaron que el tiempo de revisión de PRs podría optimizarse.
- Fue necesario ajustar los plazos de entrega para algunos módulos debido a dependencias no previstas.
- La documentación técnica de algunos componentes podría ser más detallada.

**Próximos pasos:**
- Continuar con el desarrollo del módulo de pagos.
- Mejorar la documentación técnica para futuros colaboradores.
- Planificar reuniones semanales para alinear avances y blockers.
