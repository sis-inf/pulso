## Retrospectiva del sprint
- **Lo que funcionó bien**:
  - Uso efectivo de los workflows de CI/CD.
  - Buenas comunicaciones en las reuniones diarias.
  - Avance rápido en el Auth Module gracias a la planificación clara.

- **Áreas de mejora**:
  - Algunos desarrolladores notaron que las documentaciones de APIs están incompletas.
  - El tiempo de revisión de PRs fue más largo que esperado, especialmente en el Search Module.
  - Necesitamos un sistema más claro para priorizar issues en futuros sprints.

- **Próximos pasos**:
  - Actualizar documentación de APIs.
  - Establecer un proceso más ágil para la revisión de PRs.
  - Planificar mejor las tareas para el Sprint 3.
