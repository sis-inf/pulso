## Retrospectiva del sprint
- **Lo que funcionó bien:**
  - La estructura de trabajo en equipo fue clara y eficiente.
  - El uso de herramientas de gestión de issues facilitó el seguimiento.
- **Desafíos:**
  - Algunos módulos requirieron ajustes inesperados debido a cambios en las API externas.
  - El tiempo de integración entre módulos fue mayor de lo previsto.
- **Mejoras para el próximo sprint:**
  - Mejor planificación de dependencias entre módulos.
  - Incluir pruebas automatizadas desde el inicio de cada módulo.
  - Aumentar el tiempo dedicado a la revisión de código.
