## Retrospectiva del sprint
**Lo que funcionó bien:**
- La estructura de trabajo en equipo fue clara y eficiente.
- Los revisores de código proporcionaron retroalimentación valiosa y rápida.
- La planificación semanal ayudó a mantener el ritmo de desarrollo.

**Áreas de mejora:**
- Algunos módulos requirieron más tiempo de integración que esperado.
- La comunicación sobre cambios de requisitos podría ser más proactiva.
- El uso de herramientas de automatización podría reducir el tiempo de pruebas manuales.

**Próximos pasos:**
- Continuar con la optimización de rendimiento.
- Planificar el sprint 3 con enfoque en escalabilidad.
- Establecer un proceso más formal para gestionar cambios de requisitos.
